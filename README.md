# IT Support Enterprise Lab

## Project Overview

This project simulates a real-world IT Support environment using Windows Server and Windows 11 virtual machines.

The environment includes Active Directory deployment, DNS configuration, Group Policy management, shared folders, permissions management, printer deployment, user administration, and troubleshooting scenarios.

## Technologies Used

- Windows Server
- Active Directory Domain Services (AD DS)
- DNS
- Group Policy (GPO)
- Windows 11
- Remote Desktop
- Shared Folders
- NTFS Permissions
- VirtualBox

## Project Components

### Active Directory Deployment
- Organizational Unit (OU) Structure
- User Account Management
- Security Groups

### Resource Management
- Shared Folders

### Printer Management
- Shared Printer Deployment
- Group Policy Printer Deployment
